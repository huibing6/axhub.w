## 关键业务流程

### 注册管理
服务商填写基础信息→选择服务品类（专业化品类动态加载该专业目录配置的资质附件清单）→上传资质附件→提交→系统自动校验→按品类属性自动分流：
- 非专业化：中油物采统一审核
- 专业化：中油物采审核基础信息 + 专业部门审核专业资质

> 资质附件联动：管理端"参数配置 → 专业服务目录配置 → 目录品类设置"为各专业目录配置需上传的资质文件清单（文件名称/是否必填/说明），注册服务商与准入资料的服务目录编辑区按所选品类编码读取清单并逐项上传；通用目录无资质附件要求。
>
> 审核流转：服务商所选专业品类按品类分别流转至对应专业部门审核（专业部门审核页按品类任务分发），各品类并行独立、互不排斥——任一品类通过即服务商注册成功（使用单位可立即补充MDG信息获取编码），其余品类继续各自审批，通过后自动补充纳入；全部品类驳回则需补正后重新提交。注册成功后进入待配码库 → 使用单位补充MDG信息 → 获取编码正式生效。
>
> 专业部门审核：列表页操作列提供查看/审核/进度查询，查看与审核进入审核详情页面（dept-detail）；详情页回显服务商提交的注册信息（服务商信息概要 + 服务品类 + 资质信用 + 服务能力 + 按专业目录配置的资质附件清单），审核侧重服务品类；"审批记录"Tab 展示审批流程步骤表并提供审核操作（通过/驳回+审核意见）。全部提交记录与审批记录可在"注册管理 → 注册信息查询"按申请单维度查询（提交记录 + 审批记录步骤表：步骤/受理单位/状态/受理人/受理时间/完成时间/审批是否通过/处理意见）。

### 准入管理
注册审核通过→进入待配码库→使用单位标记启用→各使用单位按模板（模板按使用单位配置，见"参数配置→准入通知配置"）独立发送补充资料通知（不同单位可对同一服务商分别发送、要求可不同、可无通知）→服务商在"准入资料"以通知列表为主入口，点击进入详情（基本信息/服务目录/资质信息三个 Tab 只读回显注册资料，补充资料 Tab 按该使用单位通知模板逐项填报上传）→使用单位核实确认（准入复核）→复核通过后填写 MDG 信息（复核详情页"推送MDG"→MDG信息填写弹窗：申请信息/基础信息/MDG信息）→推送 MDG 系统→接收供应商编码→正式生效（未配码前不可交易）

> MDG 在途限制：同一服务商同时只能有一个在途 MDG 推送流程。推送时校验，若已有其他使用单位的推送流程正在处理中，则阻止并提示等待处理完成。
>
> 准入通知模板：管理端"参数配置 → 准入通知配置"支持按使用单位维护通知模板（使用单位/模板名称/适用流程/资料项列表），支持按使用单位筛选。

### 信息变更
- 基础信息变更：服务商申请→中油物采审核→通过更新→MDG同步
- 品类剔除：提交即生效（无审批），强制记录日志
- 品类新增：系统自动路由（非专业化→中油物采/专业化→专业部门）

### 服务品类维护（改造自 1.0 服务商端）
服务商端"服务商管理自助服务 → 服务品类维护"自 1.0 搬迁并改造，**不再基于中标结果**，服务商可自由维护服务品类。页面为左右两个 Tab 页签：

1. **Tab「已注册服务品类」**：已注册服务品类表格（序号/编码/名称/级别/目录类型/使用单位[可为多个，Tag 展示]/变更类型，支持编码/级别/变更类型/提交人筛选），操作"剔除"→ 剔除原因弹窗（必填，提示剔除后即时生效不可交易、原因强制记录）→ 确认后即时移除
2. **Tab「未注册服务品类」**：
   - 新增入口卡片："维护服务品类"→ 维护页（service-maintain-add），服务商从**完整服务目录（专业目录+通用目录，无范围限制）**中自由选择任意品类（目录弹框：双 Tab 树形多选+关键字过滤+已选中计数，可多级选择）；**按品类类型填写不同资质**——专业品类需资质信用（资质等级/证书编号/信用评级/证明文件）+资质附件（按管理端"专业服务目录配置"清单上传）+服务能力（主要设备/技术优势）；通用品类无需上传资质附件（自动提示）
   - 待提交（暂存）数据：维护页/编辑页"保存草稿"后暂存，此处展示（暂存单号/品类/暂存时间），支持继续编辑（进入编辑页 service-maintain-edit，?code= 回显）、提交审核（确认后进入审核流程）、删除/批量删除

### 处置管理
- 自动触发：黑名单/资质到期→全集团冻结
- 手动冻结：全集团（中油物采）/本单位（使用单位）
- 品类冻结/解冻
